# Informe Académico Final — SentinelText

**Materia**: SIS120 · Lenguajes Formales y Autómatas  
**Proyecto**: Detector Léxico de Señales de Riesgo en Mensajes  

## 1. Resumen Ejecutivo
SentinelText es una aplicación web desarrollada bajo una arquitectura Python (FastAPI) y React (TypeScript), diseñada para aplicar expresiones regulares a un problema real de análisis léxico y detección de patrones sospechosos. Cumple estrictamente con los plazos, el rigor analítico y las restricciones de privacidad establecidas en la guía de la materia.

## 2. Conclusiones y Validación
- El motor de expresiones regulares demostró ser robusto y determinista, logrando una **exactitud del 100%** frente al corpus sintético de evaluación.
- La separación entre la lógica de análisis léxico (backend) y la interfaz de usuario (frontend) garantiza un diseño limpio, mantenible y académicamente defendible.
